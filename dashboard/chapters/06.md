<a id="five-bound"></a>

## The cubic five-contact estimate

**Header only.** At each unmarked rational a the explicit five-contact function satisfies h(a) ≤ C₃ M₅(a)³(1+log M₅(a)). The kernel proves C₃ ≤ 2^330683 from the cutoff 76,176 and the fixed primorial, improving the printed 2^330770. Thus this one pointwise inequality suffices for the full cubic header and both predecessor bounds.
